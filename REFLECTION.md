# REFLECTION.md

This submission completes all three assessment domains on a free-tier stack: yfinance feature engineering with Groq-structured reasoning, Phi-3 QLoRA domain fine-tuning on Colab T4 with a public Hugging Face merge, and a multi-agent research system with memory and file-based observability.

Architecturally I separated prompts, schemas, and business logic in Task 1 so validation failures never silently corrupt signals. Indicators are computed from first principles with explicit windows, and the momentum label is a combination rule rather than a single-indicator echo. Task 3 reuses those building blocks as traced tools; tool selection is observation-driven (fill missing memory slots, then replan for sentiment after news), and Task 3B enforces tool ACLs plus a Pydantic handoff with a mandatory writer-to-analyst critique cycle. Observability is file-first (`agent_trace.jsonl`) so reviewers can audit calls without a paid SaaS dependency, with an optional Streamlit dashboard.

For Task 2 I chose risk-disclosure compliance Q&A because generic chat would be capped under the rubric. The dataset is topic-diversified with length and keyword reports, split 80/10/10. The student (`Phi-3-mini`) differs from the teacher (Groq). Hyperparameters are justified for Colab T4 VRAM; training shows decreasing validation loss; adapters were merged and published at Hugging Face. Evaluation reports ROUGE-L, a secondary compliance metric, a ten-example hallucination review, and qualitative analysis.

With more time I would replace remaining offline evaluation proxies with full base-vs-fine-tuned generations plus BERTScore or LLM-as-judge on the held-out set, add a ChromaDB RAG fallback for low-confidence answers, and upgrade Task 3 tool routing to a full LangGraph ReAct loop with LangSmith traces. Limitations today include occasional empty free web-search results and dependence on free news endpoints.
