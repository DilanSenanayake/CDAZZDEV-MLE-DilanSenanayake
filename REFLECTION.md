# REFLECTION.md

This submission implements all three assessment domains as one reproducible free-tier stack: yfinance feature engineering, Groq-structured reasoning, LangGraph-style tool agents with traces, and a Phi-3 QLoRA fine-tuning path for financial compliance Q&A.

Architecturally I separated prompts, schemas, and business logic in Task 1 so validation failures never silently corrupt signals. Indicators are computed from first principles with explicit windows, and the momentum label is a combination rule rather than a single-indicator echo. Task 3 reuses those building blocks as traced tools; tool selection is observation-driven (fill missing memory slots, then replan for sentiment after news), and Task 3B enforces tool ACLs plus a Pydantic handoff with a mandatory writer-to-analyst critique cycle. Observability is file-first (`agent_trace.jsonl`) so reviewers can audit calls without a paid SaaS dependency, with an optional Streamlit view.

For Task 2 I chose risk-disclosure compliance Q&A because generic chat would be capped under the rubric. The dataset is topic-diversified with length and keyword reports, split 80/10/10, and evaluated with ROUGE-L plus a compliance-keyword secondary metric and a ten-example manual hallucination review. Hyperparameters are justified for Colab T4 VRAM, not left at unexplained defaults.

With more time I would re-run Task 1B and the teacher data generator against live Groq, complete Phi-3 QLoRA on Colab with W&B curves and a public HF merge, replace offline eval proxies with true model generations plus BERTScore, and deepen Task 3 with LangSmith traces and richer hedge analytics (IV surfaces). Limitations today include dependence on free news/search endpoints (occasionally empty), offline fallbacks when API keys are unset, and the need for a GPU runtime to materialize merged weights for Task 2.
